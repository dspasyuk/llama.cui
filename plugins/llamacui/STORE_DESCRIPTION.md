## Full description (Markdown)

**Llama.cui** brings your local AI models into the browser — a chat sidebar, plus a set of writing tools that work on any text you select, including inside Outlook on the web.

Everything runs against [Ollama](https://ollama.com) on your own machine. Your text never leaves it.

### Chat sidebar

- Opens in one click from any tab
- Streams responses from any model in your local Ollama library
- Clean Markdown rendering, multi-turn conversations
- Optionally ground answers in your own documents (Hive) or in live web results (Exa)

### Writing tools for any text

Select text anywhere on a page and right-click:

| Action | What it does |
| --- | --- |
| **Fix grammar** | Corrects grammar and spelling, right in place |
| **Grammar & improve** | Corrects and polishes clarity and flow, in place |
| **Shorten** | Makes the text more concise, in place |
| **Explain** | Plain-language explanation in the sidebar |
| **Summarize** | 2–3 sentence summary in the sidebar |
| **Draft a reply** | Writes a short, professional reply to the selected email |

### Built for Outlook on the web

In Outlook (outlook.com, office.com, cloud.microsoft) the menu appears right on your selection — even when the text lives inside the email body — and:

- Edits are applied **in place** in the message you are reading or composing
- **Draft a reply** drops the finished draft at the **top of your reply box**, above your signature and the quoted thread, ready to edit and send

### Private by design

Llama.cui talks to services on your own machine (Ollama on `localhost`). No accounts, no cloud inference, no telemetry — by default your prompts and documents never leave your computer, and you choose which model runs them.

### Getting started

1. Install [Ollama](https://ollama.com) and pull a model you like (e.g. `ollama pull llama3.1`)
2. Install Llama.cui and click its toolbar icon
3. Pick a model in the sidebar and start chatting — or select some text and try a writing tool

*Optional: point the settings at a local Hive server for document search, or add an Exa API key for web-grounded answers.*
